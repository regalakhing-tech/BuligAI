# Community module

**Status: structure prepared; feature implementation pending.**

Owns resident posts, comments, practical experiences, and the community feed.
Questions with answers belong in Questions; moderation decisions belong in Moderation.

Use `Controllers` for HTTP handlers, `Services` for posting workflows,
`Repositories` for persistence, `Requests` for validation, and `Views` for
escaped templates. Contributions must preserve ownership and review status.
See [module conventions](../../../docs/FILE_MANAGEMENT.md).

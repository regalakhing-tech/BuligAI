# Checklists module

**Status: structure prepared; feature implementation pending.**

Owns personal preparation checklists derived from community guide requirements.

Put HTTP handlers in `Controllers`, checklist generation/completion rules in
`Services`, owner-scoped database access in `Repositories`, validation in
`Requests`, and list templates in `Views`. A checklist is informational and must
retain its guide source. See [module conventions](../../../docs/FILE_MANAGEMENT.md).

# Guides module

**Status: structure prepared; feature implementation pending.**

Owns government service guides, requirement descriptions, application steps,
categories, and public reference links. Keep post discussions in Community.

Place HTTP handlers in `Controllers`, guide rules in `Services`, Supabase guide
queries in `Repositories`, input validation in `Requests`, and page templates
in `Views`. Add tables, explicit API grants, RLS policies, and authorization tests
when implementing persistence. See [module conventions](../../../docs/FILE_MANAGEMENT.md).
